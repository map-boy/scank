scank

Can my website hold N users? Enter a URL and a target. Get PASS, WARNING or FAIL.

Get it on GitHub

How it works

It ramps simulated users (1, 10%, 25%, 50%, 100% of your target), measures response time and errors at each step, and stops early if the site breaks.
PASS errors under 1% and p97.5 under 2 s
WARNING in between
FAIL errors over 5% or p97.5 over 5 s

Three modes

quick about 1 minute at 1, 10, 25, 50 users
target ramp to an exact number, for example 1000
limit keep doubling users until it breaks

Low-data check

Reports page size, compression, HTTPS and caching, with an estimated download time on 3G and 4G.

Use it

git clone https://github.com/map-boy/scank
cd scank
npm install
npm run scank -- target http://localhost:8080 --users 1000

Responsible use

Only test sites you own or have written permission to test. Remote URLs need --confirm-owner. One computer is not real traffic, so PASS means "likely holds", not a guarantee.
